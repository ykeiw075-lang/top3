# Описание алгоритма

## Вход

- Общая сумма `S` в целых копейках.
- Список участников: имя и целый положительный вес `w`.

## Выход

- Сумма каждого участника в целых копейках.
- Проверка: сумма всех выплат равна `S`.

## Правило

1. Вычисляется суммарный вес `W`.
2. Для каждого участника вычисляется базовая сумма `a = S * w // W`.
3. Вычисляется остаток `R = S - сумма всех базовых сумм`.
4. Остаток раздаётся по одной копейке участникам с наибольшей дробной частью
   доли. При равенстве выбирается участник с меньшим именем.

## Ручная трассировка

Вход: `S = 100`, участники `Аня — 1`, `Борис — 1`, `Вера — 1`.

1. `W = 3`.
2. Базовые суммы: `33`, `33`, `33`.
3. Распределено `99`, остаток `R = 1`.
4. Дополнительную копейку получает `Аня`.
5. Результат: `34`, `33`, `33`.
