# Разделение общего счёта без потерянных копеек

**Индивидуальный проект по теме 3**  
Дисциплина: «Алгоритмизация и программирование»  
Язык: Python 3

## Назначение

Программа распределяет общую сумму совместной покупки между участниками
по заданным целочисленным весам. Сумма задаётся в копейках, поэтому расчёт
выполняется без дробных денежных величин.

Программа гарантирует, что:

- каждый участник получает целое количество копеек;
- сумма всех назначенных сумм точно равна исходной сумме;
- остаток копеек получают участники с наибольшей дробной частью доли;
- при равенстве дробных частей приоритет получает участник с меньшим именем.

## Запуск

Из корня репозитория:

```bash
python src/main.py data/input.csv 100 examples/result.csv
```

Аргументы:

1. `data/input.csv` — входной CSV-файл участников;
2. `100` — общая сумма в копейках;
3. `examples/result.csv` — файл для сохранения результата.

## Формат входного файла

CSV-файл с разделителем `;`. Каждая строка содержит имя участника и его вес:

```csv
Аня;1
Борис;1
Вера;1
```

Вес — учебная величина, определяющая долю участника. Вес должен быть целым
положительным числом.

## Пример результата

Для входного файла выше и суммы `100` копеек программа создаёт файл:

```csv
участник;сумма_копеек
Аня;34
Борис;33
Вера;33
```

Сумма всех выплат равна `100` копеек.

## Проверка входных данных

Программа сообщает понятную ошибку и не изменяет исходный файл в случаях:

- файл не найден;
- файл пустой;
- строка содержит не два поля;
- имя участника пустое;
- имя участника повторяется;
- вес не является целым числом;
- вес меньше или равен нулю;
- общая сумма отрицательная.

## Ограничения

- Используется одна валюта и целые копейки.
- Программа не подключается к банковским сервисам.
- Расчёт является учебным и не является финансовой рекомендацией.
- Не предусмотрены возвраты, налоги, скидки и несколько валют.
